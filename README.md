# kt-solothurn-goggle

A [Brave Search Goggle](https://search.brave.com/help/goggles) for the Kanton Solothurn career path project (Squirro).

## What it does

Filters Brave Search results to only show pages from the Solothurn government career/job portals:

- `karriere.so.ch` — the main Solothurn job portal
- `karriere.so.ch/stellenmarkt/offene-stellen/` — open positions listing
- `so.ch/verwaltung/finanzdepartement/personalamt/` — Personnel Office (Personalamt)

All other results are discarded by default. Matching results are strongly boosted to rank at the top.

## Usage

Install the goggle in Brave Search by pasting the raw URL of `solothurn-career-path0.0.2.goggle` into the [Goggles dashboard](https://search.brave.com/goggles).
